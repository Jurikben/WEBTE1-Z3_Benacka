# WEBTE1 – Zadanie 3

Môj TODO List umožňuje spravovať osobné úlohy v zozname a kalendári. Po zadaní školského identifikátora načíta úlohy zo školského REST API.

## Technológie

HTML, CSS, JavaScript, Vue 3, Vite, FullCalendar a Fetch API.

## Spustenie

Potrebný je Node.js 20.19+ z radu 20 alebo 22.12+. V koreňovom priečinku spustite:

```bash
npm install
npm run dev
```

Otvorte adresu, ktorú vypíše Vite. Produkčný build vytvoríte príkazom `npm run build`.
